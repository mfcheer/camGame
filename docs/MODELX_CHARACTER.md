# Model X 小白：角色动作卡

2026-11-21，按用户要求新增特斯拉 Model X 动画形象。

- 识别：珍珠白圆润SUV、黑色全景玻璃车顶、窄前灯、四轮及独立双鹰翼门；首页与游戏同一模型，无外部模型资源。
- 性格：安静、有好奇心；风挡中的原生眼睛注视目标，眉毛担心时内收、开心时舒展；前保险杠单一微笑。脸与车体保持整体，不把车头当独立动物脑袋摆动。
- 三种逐泡回应：双门小幅舒展、车身左右轻摆、前悬轻轻抬起。8能量，一触即破，不阻塞出泡。
- 招牌一「鹰翼迎风」：双门缓缓展开再合拢，四轮留在地面。
- 招牌二「音乐轻舞」：左右交替小幅开门，车身跟随节拍轻倾，不转圈、不跳跃。
- 专属收尾「整装启程」：双门舒展后收好、车头微抬、车轮轻转，回到原位。
- 终点告别：停车转回玩家、双门展开致意后合拢，微倾车身并淡出。
- 减少动态：缩小所有开门与车身动作；暂停冻结，重开/结束复位。离场轮子滚动，不用四足步态。
- 声音：复用现有车辆柔和合成音效及已验收主动问候，无新配音；珍珠白、冰蓝、银灰纸花。

接入ID `modelx`，素材 `pearl-modelx.glb`、`modelx-preview.png`。验收记录完成后补充；真机、真人摄像头与儿童观感需另行体验。
