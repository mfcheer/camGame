# 自行车「铃铃」角色动作卡与返工设计规范

> 2026-11-21 推送时的视觉反馈：游戏内出现了实心轮盘，篮筐表情可读性和自然交互流程也有待复查。本页底部记录后续造型修订。

2026-11-21 视觉与动作规范（返工迭代）。目标是让 3 岁半孩子在头像和游戏画面里一眼认出自行车，并在横竖屏任何动作阶段均能清晰看清前篮筐的五官笑脸与前后双轮，动作中段也不发生遮挡。造型设计稿见 `design-review/bicycle-lingling-concept.svg` 与 `.png`。

| 项目 | 设计依据与返工规范 |
| --- | --- |
| 识别锚点 | 薄荷绿低跨经典车架、前后奶油白外胎大轮、珊瑚红圆鞍座、金属金铃、车把下方浅奶油色编织篮筐（嵌原生五官）。双轮始终是最醒目的特征轮廓，前后双轮轮廓清晰独立，绝不重叠。 |

| 性格与运动 | 温柔、爱探路，有一点点害羞；得到帮助会越来越勇敢。靠双轮平整着地滚动和前叉转向移动，停止时只作轻微重心摇摆，两个轮子保持平整接地，不拟人化悬空跳跃或挥手。 |
| 脸与神态 | 双眼与眉毛嵌在篮筐正面，篮筐下缘为笑口。受到注意时眼神跟随，收到能量笑口加深，眨眼时瞳孔与眼眶稳固依附在篮筐正面。眼睛保持大圆眼与深色瞳孔。 |
| 逐泡回应① | 前轮轻转半圈，车把带铃铛轻点头一次；篮筐眼睛看向能量来处。 |
| 逐泡回应② | 车身左右轻摆，鞍座与篮筐同体随动，两个轮子平整着地。 |
| 逐泡回应③ | 铃铛轻颤，前叉向玩家转向约一个柔和角度，开心眨眼一次。三种回应均约 0.7 秒，不延迟下一泡出场。 |
| 招牌庆祝一「双轮画圈」 | 原地缓慢滚动一小段弧线，前轮先转、后轮跟上，车把带动篮筐回望玩家。画面能清晰看到两只轮子协同工作。 |
| 招牌庆祝二「铃声小舞步」 | 前轮左右转向两拍，车架有节奏地微倾，金铃轻摆；车轮保持接地，不转整车圈。 |
| 专属收尾「勇敢出发」 | 两轮同时平稳加速，车身微微前探，铃铛向上轻点，眉眼舒展后回到中立位。 |
| 终点告别 | 到右侧减速停车，前轮转向玩家、篮筐回望，铃铛轻点两下致意，恢复正向后淡出；不拟人化挥手。 |
| 声音与颜色 | 复用现有柔和车辆音效通道；聚光与纸花用薄荷绿、奶油黄、珊瑚红。不新增人声配音。保留一触即破与 100ms 保护。 |

## 返工制作与验收要点

- **同源模型与头像**：首页透明头像（384×384）与游戏 3D 模型从同一原生源生成。头像采用长焦等轴视角（FOV 26°，角度 1.25 rad），消除近景广角导致的前轮过大形变，彻底解决后轮左上零件悬空，完整呈现双轮、车架与篮筐笑脸。
- **命名骨架节点**：保留并精确映射 `Front_Fork`、`Bell`、`Front_Wheel`、`Rear_Wheel`、`Basket_Mesh`、`Saddle`、`Brow_L`、`Head`、`Happy_Mouth` 等关键节点。
- **动静兼容**：暂停、切后台模拟返回、减少动态效果、重置和告别后，车架、前叉、车轮、铃铛与五官均严格复位；减少动态模式下转向和倾角幅度收敛至 25%~30%。
- **边界明确**：自动化脚本与 Chromium 测试均属于浏览器端到端模拟验收（Simulation），不替代真实物理 iPad 触控、真机摄像头 MediaPipe 追踪及真实家庭环境试玩。

## 实现与验收结果（2026-11-21 返工迭代）

- **模型与头像更新**：`src/bicycleModel.js` 更新篮筐空间坐标（抬高至 y=0.58, z=0.44，前移超越轮轴），增加车架支撑梁，修正后泥瓦弧度贴合轮径；通过 `scripts/build-rabbit.mjs mint-bicycle` 重新编译生成 `public/models/mint-bicycle.glb`（约 1.10MB）；通过 `scripts/render-previews.mjs bicycle` 生成全新等轴视角的透明头像 `public/models/bicycle-preview.png`。

- **全链路贯通**：21 位角色选择、随机、营地（`0/21`）、逐泡反应、开心演出、终点单次告别全链路贯通。
- **专项与全量测试**：`test/qa_v54_bicycle.mjs` 专项 100% 通过；隔离副本全量 54 套 `npm test` 退出码 0；Pages 子路径构建 `VITE_BASE_PATH=/camGame/ npm run build` 退出码 0。

## 2026-11-28 造型更新

- 前后轮均使用带奶油色胎边与细辐条的透空轮胎。导出的 GLB 也使用同一几何体，专项检查读取导出网格，防止隐藏的实心占位件再次出现在游戏里。
- 前轮安装在会转向的前叉上，转向时跟着车把一起摆动。薄荷色低跨车架、开口编织篮和珊瑚色鞍座帮助辨认轮廓，表情集中在浅色篮面。
