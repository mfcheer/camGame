# 彩虹星尘开屏

## 设计

参考只读项目 `/Users/mfcheer/code/mfcheer.github.io/script.js` 中 `initHomeLauncher`：原生 Canvas 2D、多色微粒、短时聚拢后揭幕。针对幼儿游戏重新设计浅天空／奶油白背景、六色星尘彩虹拱、现有兔子应用图标、彩虹小队标题和简短邀请语。无新增角色、学习内容、录音或位图。

0–250ms 星尘渐显；随显示进度（最快约4秒）从四周逐渐聚成彩虹；整体淡出与首页露出与必要资源加载完成状态绑定。不显示跳过按钮，键盘Escape仍可关闭。开屏期间首页inert防误触；关闭恢复原状态，必要时将焦点还给首页。每次打开和刷新页面均展示，不读取或写入sessionStorage；退出游戏回到首页不重演。

开场不启动摄像头、语音或新增音效；沿用原首页音乐策略。240颗粒子、DPR上限2，基于实际经过时间而非帧数。动画结束立即释放Canvas、帧请求、计时器和窗口监听。切后台/pagehide直接结束，回来不重播；开启减少动态直接展示首页，运行中切换也即时结束。无2D Canvas时不挂遮罩，绘制异常或帧请求停滞由独立定时器兜底。不改浏览器返回行为。

入口 `src/homeLauncher.js`，在Game初始化前挂载；`render_game_to_text`的homeLauncher字段反映遮罩存在状态。

## 2026-11-22 解耦开屏彩虹粒子与进度条同频卡顿

用户反馈进度条与彩虹加载节奏卡顿完全一致、显得刻意。
原因分析：
1. 彩虹粒子聚合程度硬绑定进度条数值（`gather = displayProgress`），导致进度跳变或卡顿被 1:1 复制到粒子运动；
2. 视觉内核等大文件（~14MB WASM）原本是整包下载完成后才累加一次权重，下载期间两端同时急刹，完成后瞬间大跳步。

优化实现：
1. **阻尼缓动与惯性解耦**：彩虹粒子独立追随显示进度，引入指数阻尼惯性缓动（`dt / 320ms` 时间常数），网络停顿或波动时粒子平滑减速滑行并维持呼吸流动，彻底摆脱机械同频急停感；
2. **分块流式累加**：支持 ReadableStream 的大资源下载接入分块字节流实时平滑推进，消除了整包下载阶梯式的突兀大跳步。

验证：qa_v52 专项测试 10 项全部通过，全量 55 套测试套件退出码 0，Pages 生产构建通过。3 份历史 QA JSON 基线文件保持原样。

## 2026-11-22 开屏自适应节奏、童趣文案池、矢量彩虹底弧、100%脉冲光环与舒展揭幕

根据团队与用户对齐的改造方案落地：
1. **自适应节奏（去除固定 4.5s 强制等待）**：
   - 缓存热启 / 极快场景（资源在 100ms 内就绪或 mock 环境）：走 ≤1.2 秒极速开屏秀（400ms 快速成形 + 350ms 就绪定格 + 450ms 舒展揭幕），告别死板硬等；
   - 初次冷启动：按真实流式下载网络进度弹性平滑推进，100% 就绪后舒适定格 650ms，随网速智能推进，无固定强等门槛。
2. **12 条角色联动童趣文案池**：
   - 移除冷冰冰的「正在准备必要资源…」技术用语，接入 UI 设计师给定的 12 条角色文案池（小兔系跑鞋、雪王点亮甜筒火炬、麦昆发动引擎、阿奇巡逻装备等），每次启动单行随机抽取，单行居中不折行；
   - 到达 100% 时平滑过渡为「彩虹伙伴已就绪 100%」，百分比前无多余星星图案。
3. **纯 Canvas 矢量彩虹底弧（零持续滤镜，保住 iPad 60fps 性能红线）**：
   - 坚决避免使用高开销的持续 CSS `filter: blur`；
   - 在粒子层下方绘制 6 色同心圆纯矢量圆弧，圆头端点，基础 Alpha 0.18，随粒子到达聚拢率平滑渐亮至 0.75，视觉上从散落星尘自然凝聚成完整彩虹。
4. **100% 单次脉冲光环（耗时 0.4s）**：
   - 进度到达 100% 瞬间，由彩虹中心向外荡开一圈淡金色柔和光环（半径扩展至 1.25 倍，Alpha 从 0.5 淡出至 0），一次性无常驻损耗。
5. **450ms 幕布式舒展揭幕转场**：
   - 揭幕阶段粒子赋予轻微向上浮起（vy < 0）与向左右两翼舒展散开的初速度，配合容器透明度柔和淡出，像彩虹幕布轻轻向上拉开迎接玩家；
   - 揭幕后彻底清理 DOM 容器、Canvas 绘图上下文与事件监听。
