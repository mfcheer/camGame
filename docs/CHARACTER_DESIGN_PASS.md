# 角色设计复核（2026-11-14）

面向 3 岁半儿童和 11 英寸 iPad：首页先靠轮廓认出角色，游戏里让眼神与动作回应孩子，通关时演出保持 5–8 秒。全部角色继续使用可编辑的 Three.js 原生模型与本地 GLB，未引入第三方图片、动画片音乐或原声录音。

| 角色 | 首页/游戏中的识别锚点 | 性格、动作、声音 |
| --- | --- | --- |
| 小兔 | 长耳、奶白色身体 | 耳朵摆动、跳跃；轻快啾音与柔和音符 |
| 橘猫 | 三角耳、胡须、橘色条纹 | 慢眨眼、尾巴摇摆；猫叫与较短三角波 |
| 青蛙 | 大眼、绿皮、腹部 | 蹲跳、鼓腮；呱声与较长水感音符 |
| 小狗 | 软耳、奶油色口鼻 | 摇尾、歪头；小狗叫与温暖短音符 |
| 飞龙 | 翼、角、圆脸 | 扇翼、翻滚；飞翔音与柔和长音符 |
| 金龙 | 黄色长身、须、长尾 | 摆尾、云中悬游；东方风格轻长音 |
| 闪电麦昆 | 红色低车身、挡风玻璃眼睛、闪电与 95 | 车轮加速和车身摇摆；短促有节奏的赛车音色 |
| 灰太狼 | 灰色尖耳、补丁帽、围巾、浅色缝线 | 歪头思考与得意庆祝；降低狼嚎音量和尖锐度 |
| 泰迪熊 | 圆耳、肚皮、领结 | 拥抱和摇摆；柔和三音小旋律 |
| 阿奇 | 竖立牧羊犬耳、蓝警帽、警徽和背包 | 敬礼、摇尾与巡逻；专属上行音型 |
| 乐迪 | 红白机身、宽机翼、头部侧耳机 | 起飞、挥手、空中翻滚；轻快高音型 |
| 佩奇 | 左侧长鼻、粉色大头、素红 A 字裙 | 小跳、挥手和咯咯笑；低音量柔化鼻音 |
| 托马斯 | 蓝色锅炉、烟囱、灰色圆脸、1 号侧板 | 车轮转动、汽笛和蒸汽；柔和双音汽笛 |

本轮修复了托马斯烟箱圆环侧转而遮住脸的问题。结算演出从每轮仅保证一个招牌动作，改成至少两个；车辆不会再随机做拟人式跳跃。首页 13 张头像重新取景，人物在原来的选择卡尺寸里更大。通用舞台旋律保留，角色通过音色与音符时长作轻量区分；这不是动画片原声复刻。

视觉参考： [Peppa 官方角色页](https://www.peppapig.com/en-us/characters)、[PAW Patrol 官方阿奇介绍](https://dev.pawpatrol.com/characters/chase)、[Disney Cars 官方角色页](https://cars.disney.com/)。其他角色以其现有作品的高辨识度轮廓为方向，资源均为本项目程序绘制。

验收：iPad 横屏逐个选择角色、看首页头像和进入游戏后的 GLB；戳泡泡时看眼神、表情和身体是否跟着反馈；通关时看两种不同招牌动作与声音是否只播一次；切后台、暂停、静音后检查演出和声音恢复。真实 iPad 与儿童主观体验仍需家庭实测。
