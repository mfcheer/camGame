## 近期核心形象重构与细节精修

1. **灰太狼：解决嘴巴/尾巴脱节与气质丰满**
   - 彻底重构狼王面部立体几何，增加实体下颌骨（`Wolf_Lower_Jaw`）与咬合系统，嘴唇与牙齿紧密贴合脸部，杜绝几何悬空；
   - 重新加固尾巴根部与臀部躯干的嵌合骨骼；
   - 调整标志性补丁帽（黄色双交叉补丁）与红色大领巾，表现出狡黠、自信又充满喜感的“灰太狼大王”原汁原味气质。

2. **小狗旺旺与汪汪队阿奇：萌犬元气笑容与小粉舌重构**
   - 修复阿奇吐舌歪斜（原写死偏向右侧）、发灰以及无骨骼托底悬空的问题；
   - 增加专属奶油色立体下颌骨与焦糖色下唇轮廓，让口腔和舌头具有坚实的解剖依托；
   - 小粉舌严格居中（$x=0$），自然容纳于下唇上沿，舌尖微翘，采用健康的草莓樱花粉与微呼吸轻弹动画；
   - 口腔深处内嵌两颗萌萌的纯白小犬齿，充满活力。

3. **小猪佩奇：电视动画 1:1 纯线条手绘表情系统**
   - 彻底移除原本在 3D 模型脸上的暗色张嘴洞与假舌头（避免产生“脸上挖黑洞”的怪异感）；
   - 忠实还原原版 2D 扁平卡通质感，改用纯嘴角弧线表达喜怒哀乐：
     - **受困/委屈**：嘴角向下弯曲的撇嘴倒弧（`Pig_Frown` ☹️），楚楚可怜；
     - **闲置常态**：带微微上翘笑窝的甜美微笑弧（`Pig_Smile` 😊）；
     - **欢庆获救/大笑**：大幅向上扬起至脸颊红晕的灿烂大笑弧（`Happy_Mouth` 😃）。

4. **三角龙嘟嘟：经典暖阳金橙色重构与抖动修复**
   - 摒弃发暗的橄榄绿，升级为儿童动画经典的高饱和度暖阳金橙色（`#f59e0b`）与落日暖橙大盾甲，盾甲边缘镶嵌灿烂小金珠滚边；
   - 修复被困绳索阶段由于高频动画叠加导致的四肢剧烈抽搐抖动问题，受困时四肢平稳扎根地面，通过头部微抬与尾巴摆动表达反馈。

5. **萌鸡小队麦奇与瑞奇宝宝跳跳：去繁就简，1:1 忠实还原动画极简纯真精髓**
   - **麦奇（Chip）去繁就简**：
     - **还给麦奇一张干净通透的明黄幼儿脸蛋**：彻底清除额头上繁杂生硬的多道深色条纹，还原动画中整张小脸和脑门温润纯净的阳光明黄绒毛；
     - **去除假绿叶，头顶保留纯粹的三叉小呆毛（呆毛羽冠）**：头顶中后方自然立起 3 根微翘后仰的深栗色小羽毛；
     - **纯正鲜红三角领巾**：剔除野餐布式的白色格子交叉线，还原动画片中最标志性的明艳纯正鲜红小领巾（配软萌立体圆结）；
     - **纯净暖黄小肉翅与圆萌体态**：圆润二头身软糯身躯、香草奶白肚皮、纯净暖黄小翅膀与钝化圆润的金橙小短喙。
   - **跳跳（Krashy）回归纯粹《瑞奇宝宝》极简圆球**：
     - **极简清爽天蓝圆球身体**：彻底去除胸前原本臆造的多余金色勋章与假领结，去除突兀的大白肚皮色块，还原《瑞奇宝宝》家喻户晓的纯净极简天蓝色黏土圆球体态；
     - **大黑眼去杂线**：移除眼眶上多余的眼睫毛重线条，保持纯真圆溜溜的大眼睛与清透双水珠高光；
     - **加入灵魂小兔门牙（Krashy_Teeth）**：在温柔微甜的笑嘴角上，精准还原跳跳最具标志性的两颗萌萌小白兔门牙（微突幼兔门牙），灵动传神；
     - **纯净小手脚与雪白毛球尾巴**：去除手心与脚底繁琐的多余贴片，浑然一体，背后缀着圆滚滚的雪白棉球小尾巴。

6. **超级飞侠乐迪：1:1 动画飞机机器人造型重构（告别人形白脸）**
   - **机头即头部一体化结构（Cockpit Fuselage）**：彻底剔除之前怪异的“人脖子 + 人形大白脸 + 人形腮红”大头娃娃结构，改为《超级飞侠》官方 1:1 的流线型红色喷气式机头一体化座舱；
   - **天蓝弧形大风挡驾驶舱（Cockpit Windshield & Eyes）**：飞机的天蓝色流线型弧面风挡玻璃直接充当眼睛视窗，内部嵌入宝石蓝大虹膜、深邃瞳孔与清澈水珠高光，上沿配红色导流眉檐；
   - **喷气机鼻与下颚微笑**：风挡正下方延伸出圆润的红色前鼻锥与白色机腹下颚，配亲切自信的飞行微笑嘴；
   - **标志性黄色喷气涡轮耳麦与机顶背鳍**：头部两侧装配标志性亮黄色喷气进气口耳麦（带白环圈与红色后掠小翼天线），机顶耸立背脊导流天线鳍与黄色警示灯；
   - **超级飞侠飞翼胸徽与机翼黄涡轮**：胸前佩戴经典超级飞侠金星飞翼徽章，红色后掠主翼下方挂载粗壮的明黄色圆柱喷气涡轮引擎（黑色进气旋钮与银色尾喷管），脚靴侧面嵌黄色机轮。


7. **全角色通关庆祝张嘴笑表情（Happy Mouth）专项重构：彻底告别人类肉唇与突兀肉舌**
   - **排查根因**：之前在角色获救欢庆张嘴笑（Happy_Mouth）时，部分动物与载具机械角色被套用了“上下两片肉垫唇瓣 + 突兀大黑洞 + 悬挂粉红人类大舌头”的生硬解剖结构，导致像长了人类的嘴唇和舌头，视觉体验突兀失真；
   - **麦奇（Chip）**：彻底剔除形似人类下唇的肉垫（Lower_Beak）与人类粉肉舌，还原《萌鸡小队》官方圆润小巧的纯粹鸟类金橙短鸟喙（Orange_Beak），开朗鸣叫时为小巧可爱的月牙状卡通笑口；
   - **跳跳（Krashy）**：去除深邃 3D 喉咙黑洞和大肉舌，回归《瑞奇宝宝》纯粹软萌的卡通月牙笑口与小白兔门牙（Krashy_Teeth）；
   - **阿奇（Chase）与小狗旺旺（Dog）**：彻底移除突兀的人类下唇线（Lower_Lip），下颌平滑收敛，口鼻部弧度自然；
   - **超级飞侠乐迪（Jett）**：彻底移除白色机腹上的黑色大洞和粉红肉舌，重构为与红色喷气机身浑然一体的超大开朗飞机卡通笑弧（Happy_Smile_Arc）；
   - **灰太狼（Wolf）**：张嘴欢呼时不再隐藏狼牙，而是保留招牌傲娇整齐白牙与尖尖小狼牙（Happy_Wolf_Teeth），移除了突兀的人脸黑洞；
   - **太友、托马斯、小铲车、闪电麦昆**：彻底清除车头、车头格栅与烟箱上吐出的人类大肉舌，统一重构为原汁原味的载具卡通开怀笑纹；
   - **三角龙嘟嘟（Triceratops）**：将下颌调整为与金橙皮肤一体的自然结构，消除浅色下唇突兀感。

验收：iPad 横屏与竖屏逐个选择 18 位角色、核查首页头像与 3D GLB 实机展示；戳泡泡时检查眼神、表情和身体跟随反馈；通关时两种招牌动作与音效顺畅触发；切后台、暂停、静音后检查演出和声音恢复。
