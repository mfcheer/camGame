# 连贯游玩与英语输入

按用户确认的方向，默认体验调整为边玩边听，声线与现有录音保持不变。

## 默认一击

- 戳破：计分、动物能量、表情与音效立即反馈；下一颗450ms后出现，保留400ms生成保护期。
- 英语：只读一次英文，用现有review录音；不强制重复双语，不等播放结束才出泡。
- 画面：实际开始读某词时显示图片、小写英文、独立中文行的轻量词签，约1.35秒消失，不锁定输入。
- 同轮同主题3个词，先各出现一次，再自然重复；同一轮避免同图概念重复及相邻同词。

`VoiceQueue`是游戏语音的唯一调度入口。当前词/句读完才开始另一条，快速连续命中只保留最近待播词，不补播整条历史。开场说话时泡泡可玩，最近词在短句后读；新词签可替换已经读完的开场字幕，避免多张卡叠在一起。

## 主动学习

点击词签或HUD小书本，才暂停并打开完整卡片。初次只读一次英文；点图片重听；点“听中文和英文”进入原中文→英文→中文→英文完整播报；点“继续玩”恢复，计分不变。没有自动悬停弹大卡、没有定时强制跟读。

详细卡使用游戏的圆角、奶油色、柔绿色样式，支持手机横竖屏、键盘关闭。默认游戏碰撞输入忽略按钮区域，生成位置也避让学习字幕。

## 开场/结束与后台

- 首个泡泡不等4秒问候字幕；开场句和泡泡入场同步。
- 最后一击直接解救并和动物互动，完整阅读不再是解救门槛。
- 宠物互动后，告别句和戴帽子/挥手离场同步；结果页不额外等待短句字幕。拍照仍仅手动触发。
- 暂停/后台停止队列、清除旧回调；返回恢复最近待播词。主动学习卡在后台关闭，普通暂停保留，点继续恢复游玩。
- 声音故障保留“恢复声音”入口；换轮、退出、结果页清理所有待播与词签。

## 验收

1. 问候尚未结束时，第一颗泡泡已出现并可碰。
2. 连续碰泡，动物立即加能量，约半秒出下一颗；期间无大词卡、无完整双语重复。
3. 快速命中时无重叠声音、没有稍后补播一长串词。
4. 点小书本：暂停、看图、重听、完整中英、继续；分数保持。
5. 320×568、390×844、844×390、667×240检查词签/完整卡与按钮边界。
6. 普通游玩、详细卡、问候/告别中切后台，返回后可继续，无重复计分、旧声音或残留弹层。
7. 最后一击后互动；点再见，动物说话时已经开始挥别，结果按原离场动画结束显示。
