# 自由玩与主动英语

孩子反馈“戳泡泡的时候总说话，听不懂”。当前版本默认自由玩，图片内容与自动播报独立；词库和已认可的录音、音色保持不变。

## 默认体验

- 首页“自动听英语”默认关闭，使用独立的 `camgame:autoEnglish:v1` 本地键记住家长选择；不迁移旧的“边玩边听”默认值。存储不可用仍可正常游玩。
- 关闭自动英语仍显示图片泡泡、保留每轮1词主题与主动点读。普通命中只给破裂声、动物能量、表情与音效；下一颗450ms后出现，保留400ms生成保护期。
- 开场不自动说问候句；告别时动物会自动说一句短语，动物动作、开心小演出、戴帽子、挥别与手动拍照流程保留。
- 点击HUD💬才听动物当前阶段的一句英文，可在字幕中点“再听一次”。不会要求跟读或等字幕才能继续。

## 少量自动输入

- 家长开启后每轮读同一张词卡最多2次：一次英文（review 录音）、一次中文（`audio/words/zh/` Tingting 210字/分钟标准录音），先后顺序每轮随机。中文给意思锚点，英文给目标输入。
- 每轮开始锁定1个单词（`BubbleManager.roundWord`），本轮所有泡泡与发音均为这张卡；抽选时尽量避开最近五轮出现过的词或重复概念。
- 距上一段语音结束的间隔：轮内成对的第二次发音只需2.5秒巩固间隔；第一次发音（含跨轮）仍保持至少12秒有效游玩时间。暂停、首页、结果页和后台时间不计入。主动词卡、词库点读和动物短句也计入这一间隔。
- `SpeechPolicy` 统一维护开关、次数和间隔；`VoiceQueue.playAutomaticWord` 只处理立即可播的机会。繁忙、静音、声音故障或间隔不足时直接跳过，不排队、不计为一次已播机会。
- 真正播放时显示对应图片、小写英文和独立中文行的轻量词签，发音结束后保留650ms；期间继续出泡，连续碰其他目标也不会换掉正在发音的图片。
- 最后一击不开始新的自动语音，进入开心小演出立即停止旧语音与词签。

## 主动学习

每次命中更新“刚才的单词”，即使自动英语关闭也可点击HUD📖暂停打开完整卡片。打开只读一次英文；点图片重听；点“听中文和英文”播放原中文→英文→中文→英文；点“继续玩”恢复，计分不变。没有自动悬停弹卡或强制跟读。

首页“单词小花园”保留75词分类点读。主动词卡与图鉴通过同一语音入口计时，快速换词取消旧播放，不叠音。详细卡沿用圆角、奶油色、柔绿色，适配手机横竖屏；默认游戏输入忽略按钮区域，目标生成避让字幕。

## 生命周期

暂停、后台、换轮、解救和退出均使旧语音/词签回调失效。返回点继续保留进度，不重播或补播旧词/问候；主动学习卡后台关闭，返回普通暂停。声音恢复按钮修复音频通路，不擅自朗读上次单词；仍打开的主动学习卡可恢复其点读。

`VoiceQueue.playWord`保留旧的手动排队兼容能力；实际游戏的自动入口不使用待播槽位。主动学习可抢占自动词，动物短句必须显式点击。不要恢复“每戳一次自动读一次”的默认规则。

## 验收

1. 清除本站自动英语设置后打开首页，开关未选中；完整解救一轮没有自动人声，图片、破泡声、动物反馈和后续演出完整。
2. 开启英语后游玩三轮：每轮同一词卡最多一英一中2次（顺序随机）；第一次发音不足12秒有效间隔可整轮不播；没有延迟补读、连续串播。
3. 自动词播放时继续戳泡泡：即时充能和出泡，对应词签保持至发音结束后消失。
4. 关闭自动英语后点击📖：暂停、英文重听、完整中英、继续；没有重复计分。点💬才出现问候字幕和语音。
5. 单词/问候播放中暂停或切后台，返回继续无补播、残留词签或重复计分；间隔不因后台等待缩短。
6. 首页、HUD三按钮、词签、主动卡/问候在320×568、390×844、844×390、667×240完整显示。图鉴点读后进入游戏遵守静默间隔。

模块专项：`test/qa_v32_quiet_play.mjs`（静默间隔与成对预算）、`test/qa_v33_bilingual_pair.mjs`（同词卡一英一中浏览器闭环）。iPhone Chrome真实系统中断、真实摄像头和孩子主观体验仍需家庭实测。

## iPad 11英寸目标大小

平板空间（短边至少740px、长边至少960px；粗指针触控设备兼容短边缩至650px的浏览器工具栏空间）使用210–240 CSS px基础泡泡直径，再乘动物原有大小系数。横竖方向取同一短边，旋转不会再降为手机120px上限。几何、图片、碰撞与生成避让共用同一尺寸；手机及720px高普通桌面保持原基准。六动物、果冻/彩虹/双人爱心需一并检查。此处为浏览器布局尺寸，不承诺设备物理厘米数。

触控模拟专项：`test/qa_v32_tablet_browser.mjs`，覆盖1194×834与834×1194、旋转保留计分、真实触屏事件命中、完整解救与六动物预览/主动点读。此为桌面浏览器触控仿真，不替代iPad真机体验。

## 一碰就破

普通、彩虹、果冻、爱心均只需一次有效触碰。果冻保留软弹外观、破裂音效与2份能量奖励，移除层数标记、二次触碰与收回再戳要求。亲子爱心任一玩家碰任一侧或中央图片立即破裂，不再要求两人分别就绪或等待合并。保留新目标生成保护、指尖新鲜度与防重复计分，避免旧手位自动连续计分。

## 词库扩充

新增形状、颜色、教室、玩具、动物、身体部位及老师课程照片中适合看图的词；复习词与原有条目去重并记录来源。绘本来源与动物朋友分开。最近五个词的概念在条件允许时避开，单轮仍使用同一张词卡；默认不自动播放单词，启用后沿用中英文配对及原有间隔；动物告别短语按现有流程播放。
