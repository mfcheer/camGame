# 多卡游玩与轻量播报

每局从同一主题选取3个不同的词，泡泡依次轮换；相邻泡泡不重复。换轮选词继续尽量避开最近五次选中的概念；旋转屏幕保留当前泡泡和词卡，不多抽一次。

首页自动英语默认关闭，词图和破泡反馈始终保留。开启后，每轮最多触发2组自动语音，每组对命中词固定播放中文一次、英文一次；上一组结束后至少4秒有效游戏时间才可触发下一组。正在播报、静音或音频异常时直接跳过该次机会，无积压、不补读；最后一击不启动新语音。连点时保留正在说的图片词签直到该组结束，词签与实际语音对应；右上角词卡仍指向最近戳破的词。

自动语音只使用现有中文和英文短音频，不修改原配音。播报期间背景音乐和程序合成效果声音量降低；结束、取消、暂停、后台时恢复，避免语音与音效竞争。暂停/退出/换轮立即取消旧组，不会在回来时补播中文或英文；主动点读仍可抢占自动语音。

验证：`node test/qa_v35_multicard.mjs` 覆盖三卡轮换、固定顺序、忙时跳过、声音恢复、取消与词签归属；`test/qa_v33_bilingual_pair.mjs` 覆盖浏览器触控与两组录音。
