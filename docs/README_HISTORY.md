# 《彩虹小队》亲子摄像头体感游戏 (Three.js MVP v0.3)

专为 **3 岁半幼儿与爸爸妈妈** 打造的双人同框亲子体感 Web 游戏。

---

## 一、核心玩法与体验设计 (v0.3 升级)

- **纯粹单动作**：只需伸出任一只手触碰浮现的大泡泡，无需手指精细戳戳、举手召唤或张开双臂。
- **直观镜像沉浸**：全屏镜像摄像头作为背景（如同照镜子），未开启或模拟模式为柔和晴空渐变底色。
- **手部彩色光晕 (v0.3)**：
  - 1 号玩家暖黄色 (`#FFE36E`)，2 号玩家亮蓝色 (`#69C8FF`)；
  - 包含实心柔光核、半透明光晕与外圈环，边缘带 3 颗旋转小星点；
  - 靠近泡泡时自动放大加亮，碰破瞬间在 160ms 内闪出光环，即时反馈极佳。
- **主次鲜明的视觉层级 (v0.3)**：
  - 热气球缩小并根据视口自适应沉底定位（横屏 0.74H，竖屏 0.81H），为大泡泡留出充足活动空间；
  - 泡泡带有 2.5~3px 实线高辨识度彩色轮廓与外柔光圈（5 色渐进），浅色衣服与实景客厅一眼辨识；
  - 泡泡具备 0~320ms 弹性弹入动效、2.2s 待机呼吸缩放与浮动，手靠近时产生轻微视觉吸附与加亮。
- **灵动的小熊表情与动作时序 (v0.3)**：
  - 视线追踪：小熊头部与眼睛高光实时追随当前泡泡移动；
  - 阶梯表情：1~5 分分别对应点头、左右抬爪、张口笑拍爪、期待抬头、大笑欢庆；
  - 起飞时序：达成 5 个泡泡后，停顿 400ms 期待沉浮，随后平稳升空并欢快挥爪，5 秒后呈现家长结算卡。
- **UI 收敛与引导 (v0.3)**：
  - 模拟模式横幅改为左下角非交互暖灰角标（“鼠标／触屏模拟”），不遮挡游戏画面；
  - 首个泡泡引导手势位于泡泡空白侧，首次碰破后永久淡出，后续不重复打扰；
  - 摄像头权限拒绝时提供易懂的中文友好提示与一键切换模拟模式入口。
- **人体校准与舒适伸手区**：取景校准时动态检测玩家身体中心与手臂跨度，计算各自可达的舒适区间；双人模式下泡泡轮流交替落在各自可达区，避免孩子够不到或成人包办。
- **本轮玩家锁定与旁观者防替入**：正式开局后锁定参与玩家，第三人或路过旁观者不会自动替入或扰乱已有进度。
- **全比例横竖屏安全视口**：泡泡生成边界预先扣除最大可能放大半径（含 1.25 倍助力放大与浮动），在电脑宽屏及手机竖屏（如 390×844、320×932）下完整泡泡绝不出屏。

## 三、文件目录与架构

- **`index.html`**：主入口页面，包含全屏镜像 `<video>`、Three.js 画布及儿童友好 UI 覆盖层。
- **`src/`**
  - **`config.js`**：关卡与配置中心（首版锁定小熊嘟嘟 `targetBubbles: 5`）。
  - **`main.js`**：游戏主状态机（`START` -> `CALIBRATING` -> `PLAYING` -> `PAUSED` -> `CELEBRATING`），单人/双人协同、就绪门禁、异步轮次取消保护及庆祝定时器分段恢复管理。
  - **`sceneManager.js`**：Three.js 场景管理、透明背景渲染器、柔和卡通光照、底部小草坡与雏菊（高度 <= 0.12H，不压吊篮）。
  - **`hotAirBalloon.js`**：纯 Three.js 几何体程序化可爱小熊、头部旋转与视线高光追踪、爪子拍动、5 段彩虹发光充能环、期待停顿与升空庆祝。
  - **`bubbleManager.js`**：彩色轮廓大泡泡、弹性出场、呼吸浮动、吸附增亮、破裂闪圈、粒子爆发、能量光团弧线飞行、双人黄蓝手晕反馈。
  - **`poseDetector.js`**：本地 MediaPipe PoseLandmarker 封装（支持 2 人同框，水平镜像与 cover 裁剪映射，本轮玩家锁定与旁观者防替入，退出即释放摄像头）。
  - **`audioManager.js`**：Web Audio API 纯本地合成童趣音效（清脆水泡 Pop 声、五度大调进阶音阶、起飞欢庆和弦），无外链资源依赖。
  - **`uiManager.js`**：5 个发光星点、模式选择、取景校准门禁、首次引导淡出、左下角模拟角标、友好异常弹窗。
- **`public/`**
  - **`models/pose_landmarker_lite.task`**：本地姿态检测模型（5.6MB），完全本地离线加载。
  - **`wasm/`**：MediaPipe 官方 WebAssembly 运行包，零外链依赖。
- **`test/`**
  - **`qa_acceptance.mjs`**：18 项源码级生命周期与集成自动化回归测试。
  - **`qa_closeout.mjs`**：12 项专项行为与边界检查。

## 五、隐私与安全性

- **完全离线处理**：所有摄像头视频帧均在本地浏览器通过 WebAssembly/WebGL 本地运算，绝不录制、不保存、不上传任何视频或骨骼关键点数据。
- **生命周期释放**：在点击“退出回首页”、页面隐藏后台（visibilitychange）或关闭页面时，立即调用 `MediaStreamTrack.stop()` 释放摄像头硬件。
