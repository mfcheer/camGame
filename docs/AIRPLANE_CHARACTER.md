# 小飞机 云朵：角色动作卡

2026-11-21，用户要求新增飞机，重点设计表情、神态和动作。

| 项目 | 设计 |
| --- | --- |
| 识别锚点 | 原创蓝白小客机，长圆机身、宽机翼、双发动机、竖尾翼、三点起落架；不变形成机器人。首页与游戏从同一原生模型生成。 |
| 性格与运动 | 温和、认真、得到帮助后轻快；8份能量。离场先沿跑道滑行，随后抬头低空飞行，不做动物蹦跳。 |
| 注意与神态 | 驾驶舱为蓝色玻璃，白眼珠和深蓝瞳孔随目标、能量与玩家移动；担心时眉头轻收，好奇时微抬眉、轻偏机头，获救后眉毛舒展。保留驾驶舱眼睛及嘴，不使用星星眼或人类手臂。 |
| 逐泡回应 | ①机头轻抬、尾翼回应；②整机轻压左右翼；③尾舵左右摆、机头轻点。约0.7秒，不阻塞出泡。 |
| 招牌庆祝一 | 跑道热身：起落架轮子转动，机身前后轻俯仰，始终贴地。 |
| 招牌庆祝二 | 云间压翼：整机小幅升起，左倾→右倾，固定机翼不扑扇。 |
| 专属收尾 | 迎风起飞：机头渐抬、机身短暂升起，尾舵轻摆，舒展眉眼后回到原位。 |
| 终点告别 | 转回玩家，左右轻压翼并摆尾舵，保持低空姿态后淡出；不挥人手、不鞠躬。 |
| 声音与配色 | 轻柔的合成上行提示音（复用现有飞行音效），走现有音效总线；天空蓝、奶白、金黄纸花。主动问候只复用已验收短句，无新增人声。 |

接入：`airplane` / `cloud-airplane.glb` / `airplane-preview.png`。与已有乐迪并存，随机、营地、问答、奖励使用统一链路，不新增玩法门槛。

验收待完成：原生及GLB一致；三种得分回应、两段庆祝及收尾、终点告别；暂停/后台不推进、减少动态、复位；iPad横竖屏完整闭环。真实摄像头与iPad听感/性能须如实区分模拟。
