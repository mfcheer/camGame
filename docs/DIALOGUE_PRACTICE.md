# 解救后的手势问答

2026-11-17 用户确认：无需“聊一句／告别”入口，自动提问，再出现两个回答泡泡，用摄像头手势选择，回答后自然告别。第一版不做语音识别、不要求孩子说话、不增加通关门槛。

## 流程与声音边界

最后一泡立即计分 → 当前读词、词签收起 → 直接进入对话 → 播完问题再开放两颗固定大泡泡 → 一次触碰选择 → 英文完整回答 → 留3.5秒有效时间跟读 → 同一句结束语先中文后英文、角色原有终点告别 → 结果页。

每轮一题，优先呼应本轮真正碰破的内容，采用[明确对应表](DIALOGUE_CONTENT_LINKS.md)，排除上一题型，候选中优先选择近期较少问到的一组，相同次数随机。无候选时按独立游标继续心情→天气→认物→颜色→数量→水果喜好→饮品选择的原轮换，并跳过上一题型。关联观察题固定匹配场景；无关联时沿用各组独立场景轮换。对话代替此前获救后等待交互的演出入口，原 HappyPerformance 角色动作资源和能力保留。对话中的角色位于两颗泡泡中间、跑道前方，使用原有五官、倾听待机和各角色 friendReact；难过时仅安静陪伴，不触发欢快回应，不新增统一庆祝动作。告别仍走各角色原有专属姿势。

**这是用户明确确认的自动人声例外**：解救后自动读一次英文问题、一次最终回答；不受家长“自动听英语”开关限制，但遵守总静音。泡泡游玩阶段的自动读词规则不变。对话声音仍经过 VoiceQueue 与 SpeechPolicy 的统一发声／静默记录，不另外建立声音通道；问答结束后告别短语沿用已验收的中英录音，先中文后英文各一遍，结果页等待告别播报完成（仍有失败超时），暂停／后台取消后不自动补播；不播放完整双语，不拼接单词、不在玩家端请求TTS。主动“再听”可重播当前问题或最终回答，不重复计分。顶部“听朋友说”在对话中也转到当前对话重听。

首次问句正常播完才开放碰撞，保护期400ms；到新界面时已经位于目标内的指尖不触发，需要离开再进入。只用观察到的有效食指尖；每帧只接受第一个进入目标的手，一次划过两个答案只能选一项。图片与碰撞都是同一个 DOM 圆形边界（椭圆距离判定），指尖光点也使用同一坐标，不使用掌心、拇指或捏合。横竖屏不改变选项顺序，布局变化后重新保护。回答泡泡成组居中，横屏间距 clamp(24px,10vw,120px)、竖屏 clamp(24px,6vw,64px)，保留原目标大小，避免选项靠屏幕两侧让孩子难以伸手够到；碰撞直接读取调整后的 DOM 边界。

问答角色按模型最低点放在实际跑道表面上方，并按题图、两个泡泡和屏幕边缘的可用空间缩放。平板尺寸为角色留出更宽或更高的展示空间，旋转后重新计算站位。矮横屏缩小题图和泡泡以容纳全身。

没有选择时，等待12秒有效时间后直接告别，无倒计时、催问或奖励损失；问题／回答的加载与播放各有8秒有效时间兜底，超时释放语音、推进画面。底层媒体加载和播放仍有既有超时。暂停、后台、退出和重开立即取消声音并让旧Promise失效。返回保持暂停；主动继续解锁音频，保留画面和已选答案，不自动重播。被打断的问题恢复为可选答案，被打断的回答恢复跟读停留；仍可手势或触屏主动重听。等待计时冻结，恢复时不重新读题。

## 首批内容卡

| 字段 | 心情 feelings | 天气 weather |
| --- | --- | --- |
| 问句 | How are you today?／你今天感觉怎么样？ | How’s the weather today?／今天天气怎么样？ |
| 回答 | I'm happy.／我很开心。；I'm sad.／我有点难过。 | It's sunny.／今天是晴天。；It's rainy.／今天下雨。 |
| 情境 | 表达孩子自己的感受 | 明确标“看看这里的天气”“游戏里的天气”，按图观察，不声称知道孩子当地天气 |
| 关联概念 | happy、sad；sad 仅作本组回答，不顺带扩充126词词库 | sunny、rainy；rainy 同样仅作回答 |
| 静态构图 | 同样的圆脸、五官和肤色，仅嘴形区分；暖色面颊，不用夸张泪水或否定符号 | 太阳／云与雨滴，两张圆润绘本矢量；场景上方展示与正确答案相同的天气图 |
| 关键动作 | 没有需要教学的过程性动作 | 没有需要教学的过程性动作 |
| 表现选择 | 静态表情即可理解，不添加无关动画 | 静态图能表达天气，不用物体漂动假装动作短语 |
| 判断 | 两种都成立，没有正确／错误之分 | 第一次不符：描边强调场景，1.6秒后重新选择；第二次仍不符：展示并读出场景对应答案，不读错误选择 |
| 回应 | 开心沿用角色自身回应；难过安静倾听并显示“我陪着你，难过也没关系” | 正确或示范后沿用角色自身回应，不加分、红叉、失败音 |

## 资源和制作方法

唯一文本源 `src/dialogueContent.js`；每句完整英文独立生成，六句各具完整中→英→中→英、英文短读、中文短读，共18份静态MP3。`public/audio/dialogue/{id}.mp3`、`review/{id}.mp3`、`zh/{id}.mp3`。标准生成器增加 `dialogue`、`zh-dialogue` 两种 kind，仍读取 `scripts/voice-profile.json`：英文 Kokoro-82M / af_heart / 0.92，中文 Tingting / 210。完整双语与中文短读作为后续主动学习入口资源储备，本版游戏仅播放英文短读；不自动轮播中文。

```sh
python3 scripts/build-natural-phrases.py --kind dialogue --dry-run
python3 scripts/build-natural-phrases.py --kind zh-dialogue --dry-run
uv run --no-project --python 3.12 --with kokoro==0.9.4 --with soundfile python scripts/build-natural-phrases.py --kind dialogue
python3 scripts/build-natural-phrases.py --kind zh-dialogue
```

新增单句先登记并写内容卡，再用 `--only dialogue-<id>` 定向dry-run和生成；修改已存在句子需再加 `--force`，不得整库覆盖。沿用双向裁静默、统一母带和低峰值补偿；参数、文本、路径与SHA256登记到 `docs/voice-manifest.json`。

四张静态图路径 `public/images/dialogue/{happy,sad,sunny,rainy}.svg`；来源为项目原创、可复现 `scripts/build-dialogue-art.py`，无外链、文字、脚本或外部字体。题目若依赖过程性动作，仍先按 LEARNING_PHRASES.md 内容卡制作封面＋无声动作图，不能直接沿用本版静态图模板生成任意动作。

## 后续智能体交接与验收

1. 内容卡写清问题、所有回答、中英文、情境、自由表达或观察判断、正确答案来源、提示及退出规则。星期题未接入；后续必须按设备当地日期生成对应答案，不能固定 Tuesday。
2. 每句生成三种录音，每个答案有独立静态图；观察题提供明确场景，图片与答案保持一致。轮换不连续同题，不能把心情设为单一正确答案。所有新资源支持 Pages 子路径。
3. 运行 `node test/qa_v46_dialogue.mjs`、完整 `npm test`、Pages构建，保护原有QA报告。检查旧单词/短语资源哈希未变。
4. 在指定浏览器用真实输入或明确标注的模拟指尖走完整0→目标数、最后读词、问句、两个泡泡、答案、原有告别、结果和重开；检查截图。验证初始手占用、一次扫过两个、双手同时接触、触屏兼容、重听不重复奖励、两次天气误选、无回答退出、慢加载超时。
5. 验证提问/回答/等待中的暂停、切后台、回来仍暂停、继续不自动播音，以及退出/重开旧回调不补播。用11英寸iPad横竖屏尺寸看图片、动物全身和触碰目标；尺寸模拟不等于真机摄像头、音频中断或儿童辨识度验收。
6. 声音须分别记录技术解码、响度检查、主观试听和真机结论，不能互相替代。
