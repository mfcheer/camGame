# 词卡插画重绘记录

使用内置 imagegen 生成透明背景插画，转为 512px WebP 供词库、详情和泡泡共用；旧 SVG 保留。

共同提示：面向幼儿词汇游戏，温暖亲切的儿童绘本风格、圆润造型、柔和色彩、适合缩小识别，主体居中、透明背景，无文字、标签或水印。

- face：正面完整儿童脸，五官清楚，温和微笑。
- eye、ear、mouth、nose：儿童分别用手指指向眼睛、耳朵、嘴巴、鼻子，面部和手完整可辨，避免脱离身体的特写。
- hair：儿童头部，头发丰满且为画面重点。
- elbow：儿童弯曲一只手臂，用另一只手的食指指向手肘，手臂连接自然。
- happy：孩子露出明显开心的大笑，眼睛明亮、脸颊红润。
- sheep：全身白色卷毛绵羊，面部、耳朵及四条腿清晰可辨。

产物位于 `public/images/words/learning/`，文件名为各词 ID 加 `-v2.webp`；词和配音未改动。
