# 动物玩法差异交付

## 本轮行为

六个能量目标保持 5/6/8/10/12/9；每局首颗目标保持安稳，从第二颗开始区别玩法。统一食指触碰，不引入新的手势或识别模型。

| 动物 | 玩法 | 目标节奏 |
| --- | --- | --- |
| 小兔 | 安稳入门 | 目标稍大且集中，无主动位移 |
| 青蛙 | 荷叶弹跳 | 每周期约三分之二时间停稳，小跳高度最多24 CSS像素；加入双层果冻 |
| 橘猫 | 慢漂追踪 | 缓慢横向漂移，附轻微纵向变化；加入果冻 |
| 小狗 | 轻快连击 | 小幅轻快弹动，出场间隔700ms、可操作连击窗口2400ms；保留果冻与连击奖励 |
| 飞龙 | 云间弧线 | 较宽弧线、少量固定果冻和彩虹组合 |
| 金龙 | 祥云游动 | 舒缓的双频曲线，较早出现彩虹，再遇到果冻 |

手指进入接近区时目标停在当前位置，果冻首击后保持停住。超过约5秒未命中或多次接近未成功时，辅助逐渐增强：降低运动速度、减小摆幅、增大目标。连续三次顺利后才小幅恢复，恢复幅度限制为每次0.08，不超过动物默认难度。沿用不计时、不扣能量的规则。

运动按CSS像素定义，投影边界包含帮助放大、光晕、果冻回弹及3D前后表面的透视。目标同时约束在人体现有舒适区；空间狭窄时自动限制活动范围。暂停冻结时钟，旋转保留动作进度，重开清理辅助。

双人普通目标保持归属，第四颗合作目标优先于其他特殊泡泡。新增玩法暴露的模拟模式问题已修复：单个鼠标跨中线改变角色时，实际移出果冻仍能解除上一角色的按住状态；另一位真实玩家不会解除当前玩家的按住状态。

## 用户验收

1. 依次选择六种动物，戳完首颗后先收回手，观察第二颗，比较静止、弹跳、慢漂、轻快、弧线与祥云曲线。
2. 指尖接近移动目标但暂时不戳，确认泡泡停住；移开后继续运动。果冻首击后不再移动，收回再戳可完成。
3. 某颗泡泡等约7秒，观察目标变得更容易；完成几个目标后也不应突然变快。重开恢复原有节奏。
4. 玩到果冻首击后旋转手机，确认剩余层数与进度保留；暂停再恢复，不应跳过一段运动。
5. 两人选青蛙，完成普通目标、果冻和同心泡泡。鼠标模拟双人模式时，将指针移到屏幕另一侧后再回来，也能完成果冻第二击。

以上浏览器交互使用鼠标模拟，真人摄像头及儿童手感仍需真机体验。没有把这些容错改进等同于识别模型准确率或推理速度提高。
