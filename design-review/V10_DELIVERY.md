# v0.10｜成功奖励重设计与两位新朋友

2026-11-13。用户要求重做皇冠、花环和探险帽，并新增青蛙、小狗。

## 交付

- 皇冠：曲面五尖金冠、孔雀绿绒带、金色卷边、珍珠冠尖、蓝绿切面主宝石与粉色侧宝石。
- 花环：不对称多层玫瑰、雏菊、月桂叶、紫色花苞、飘带与露珠。水平贴合头部，取代原先简单的花朵拱圈。
- 探险帽：平滑帽顶、曲面皮边帽檐、青绿织带与缝线、黄铜护目镜、羽饰和徽章。
- 三款仍沿用现有随机奖励和头部跟随逻辑；静态细节按材质合批，避免每个花瓣、宝石各产生一次绘制。
- 青蛙呱呱：6个泡泡，宽头、上凸大眼、蹼趾、皮肤斑点和淡黄肚皮；收到能量蓄力跳，解救后大跳离场。底部配荷叶、水花和冷绿池塘小径。
- 小狗旺旺：10个泡泡，奶油色身体、垂耳、棕色眼斑、宽口鼻、红领巾和粗尾；抬爪回应、摇尾、四足跑动，终点坐起挥爪。配暖色花园小径、玩球和骨头装饰。
- 开始页四种动物均可选，随机和5秒自动下一轮覆盖全部四种；手动再玩保留当前动物。10格能量条、松绳进度和移动布局已适配。

原生3D资产源：`src/celebrationAccessories.js`、`src/frogModel.js`、`src/dogModel.js`。新GLB位于`public/models/pond-frog.glb`与`sunny-puppy.glb`，可运行`npm run build:assets`重新导出。预览生成使用`scripts/render-previews.mjs`，需要可用的Playwright和5175预览服务。
