# 单词互动与卡片体验

用户要求：继续完成单词功能的体验调整，英文显示小写，中英文分行，关注整个卡片的 UI 与交互效果；保持三岁半儿童的解救游戏为主。

## 最终行为

- 21 个英文单词全部小写；图片、英文、中文三个层级。深色英文放大，中文单独一行，不再使用浅黄色底上的白字。
- 竖屏使用纵向卡片；高度不足 400px 的横屏使用左图右文，英文与中文仍各占一行。长词 rectangle 不换行。按真实卡片尺寸避让安全边距与顶部 HUD，旋转时重新定位。
- 出现 240ms、退出 180ms；卡片驻留由播报流程控制，取消原先 4.5s CSS 淡出。尊重减少动态效果设置，卡片不拦截触摸。
- 以 Web Audio / HTML Audio / 语音合成的 ended 回调推进。播报时降低背景音乐，结束后恢复。备用语音保持中文→英文→中文→英文。
- 卡片最少展示 2.8 秒，音频结束后再留 550ms 阅读空隙；设备不返回 ended 时，12 秒有效时间保护防止永久卡住。静音不影响看图。
- 暂停停止当前声音并隐藏卡片；恢复后显示并完整重播，重新计算阅读时间。退出、重开、识别错误清理卡片与声音；旧加载结果和回调不能推进新一局。
- 单词展示结束后才交付动物能量反馈、生成下一颗泡泡或进入解救后互动。先动物互动，再告别/戴帽子/摄像头合影的已有顺序保留。
- 每局从一个主题选四词，袋式轮换保证先看完四词再重复，不连续重复。每轮重新选；当前泡泡旋转不换词。
- 首页“玩法提示与隐私保护”内可关闭“听单词、看图片”，进入无单词的纯解救模式，默认开启。

## 图片

- 颜色使用清晰色块，形状保持实际轮廓并去掉表情干扰。
- 其余物品保留原生可编辑矢量造型，放大主体、减轻阴影并加柔和体积色；直接使用矢量，避免放大 256px PNG。生成源为 scripts/refresh-word-art.mjs。
- “老师”使用新生成的课堂插画，优化为 640px PNG。提示方向：面向幼儿的温暖立体插画，老师站在黑板前，手持书本示意讲课，无文字、无水印。
- 泡泡和弹出卡片统一使用同一张词图。原有 PNG 和 SVG 保留作兼容后备。

## 验证与家庭验收

自动化：全量 npm test，包含新增 14 项时序/播放生命周期/选词/纯游戏行为回归；生产构建；标准网页游戏客户端；实际浏览器鼠标碰撞、真实音频结束、暂停恢复、最终单词→动物互动→告别→结果；21 词 × 5 个手机尺寸的边界、分行、长词和图片容器检查。截图与浏览器结果存放 output/playwright/word-learning/（本地忽略文件）。最终完成情况见 progress.md。

家长体验：手机竖屏和横屏分别看 rectangle、teacher；播报中暂停再恢复；最后一颗泡泡确认播报完才互动；关闭单词开关玩一轮。音色、儿童愿意停留多久、真实摄像头交互和移动真机帧率仍由家庭体验确认，浏览器视口模拟不代表真机通过。
