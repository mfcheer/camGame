# 节奏、无文字示范与可选拍照

用户本轮要求：先做节奏优化和无文字示范；保留戴帽子，拍照仅允许手动点击按钮触发。

## 交付行为

- 本轮首次碰到一个词，仍播放完整中文→英文→中文→英文；同轮再次碰到该词，只播放一次英文。21段独立英文短音频由本地Samantha语音制作，平均约0.59秒，源脚本 scripts/build-review-audio.mjs；部署直接使用已生成MP3。
- 新词卡至少2.8秒，复习/主动重听卡至少1.5秒；都等待实际音频结束，随后分别留400/250ms阅读、200ms退场。词卡结束后的出泡间隔改为450ms；纯游戏原节奏不变。正常设备上复习词破泡后约2.2秒可到下一目标，加载、暂停或较慢播报会继续等待。
- 图片有重听按钮。摄像头/模拟指尖需要先离开，再停留图片350ms才重听；原地保持不会自动循环。停留期间暂缓退场，重复播放不增加分数或生成重复能量。暂停重播保留当前播报类型，重开清除本轮熟词记录。
- 首次碰泡泡和六动物宠物阶段增加半透明食指和移动路径：点触、摸头、碰荷叶、带领移动。示范只控制可视效果，不进入追踪、碰撞、计分或解救记录。真人指尖靠近会让开；暂停冻结、旋转重定位；短屏缩小手势，摸头手势侧放、跟随手势移到动物前方，避免挡脸。
- 首次尚未成功的宠物互动保留12秒无操作示范时间；成功后沿用8秒最短闲置收尾与最后一次动作后4.5秒，整体上限20秒，可随时说再见。后续见过的朋友减少首次等待。
- 戴帽子庆祝继续自动出现在宠物互动结束后的挥别阶段。无论是否开启摄像头，挥别后默认直接显示成果，绝不自动倒数、快门或生成拍立得。
- 有真实播放中的摄像头时，成果页显示“拍张合影”；只有点击按钮才进入倒数。倒数可取消、暂停，主动拍好的合影保留，支持下载和重拍。取消重拍保留旧照片；摄像头断流回到干净成果；退出/重开/识别错误撤销待拍状态。

- npm test：27套全量脚本通过；本轮新增15项行为专项，覆盖短音频、独立缓存、熟词生命周期、手动与指尖重听、阻止误计分/旧回调、示范/真实输入分离、首次引导、短屏、戴帽子、仅显式拍照和取消。
- 标准网页游戏客户端执行并打开最终截图/文本状态；Pages子路径生产构建通过。
- 实际浏览器完成兔子五次鼠标命中，验证新词、同词复习、按钮/指尖重听、单次计分、宠物示范→真实回应→告别→纯成果。其他五动物从准备好的最后一步进入互动，完成三种横竖屏尺寸、真实鼠标回应、暂停与告别，无页面错误。
- 使用真实MediaStream测试视频和合成脸锚点验证：先互动、后戴帽子、直接无照片成果；点击后倒数；暂停/取消；渲染后一次抓拍；照片保留；重拍断流；退出撤销。不是实人人脸贴合或识别准确率结论。

## 家庭验收

1. 选小兔玩一局：前四个词完整介绍，第五颗会复现已听词，只读一次英文；卡片保持小写英文与中文分行。碰一下重听按钮，或食指移开后停留图片，确认只重听、不额外得分。
2. 解救后看示范食指，再碰小爪/摸头/碰荷叶/移动指尖；检查实际操作时示范让开，旋转和暂停后位置正常。示范不应自己完成互动。
3. 开摄像头：互动后仍戴帽子，成果直接出现；不点击拍照时没有倒数和快门。点击“拍张合影”后才倒数，可取消或重拍。
4. 真机检查动作易懂程度、语音听感、指尖重听的舒适度和横屏显示；这些依赖实际设备与孩子体验。
