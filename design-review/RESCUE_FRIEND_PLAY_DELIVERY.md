# 解救后互动交付

## 新的成功流程

最后一份能量抵达 → 绳索解除 → 动物走近邀请互动 → 自然/手动告别 → 原有离开与挥爪 → 有摄像头时倒数合影，否则展示纯成果页。

动物不再刚脱困就立即跑走。主游戏仍用同一食指，不引入捏合、拖拽松手等规则。

| 动物 | 互动 | 回应 |
| --- | --- | --- |
| 猫 | 轻碰额头，或在光圈内轻轻移动 | 眯眼、歪头、摆尾、拟声、爱心 |
| 狗 | 碰举起的小爪子 | 爪子回弹、摇尾、吐舌、开心叫声 |
| 兔 | 碰举起的小爪子 | 笑眼、小跳、耳朵弹动 |
| 蛙 | 碰下一片发光荷叶 | 沿短弧跳过去，再提示不同的下一片 |
| 飞龙、金龙 | 移动食指 | 平滑跟随，翼/身体/尾巴摆动；移动一段后回应 |

## 体验和边界

- 出现发光圈、简短提示；模型放大并移到较容易伸手的位置，使用已检测的舒适范围调整爪子/头部/荷叶高度。
- 不显示倒计时；不操作约8秒自然收尾，互动可延长停留，上限20秒；「和朋友说再见」可提前继续。
- 击掌需要收回再碰，静止指尖不持续刷回应；猫可以轻轻抚摸；双龙静止跟随点不持续播放叫声。
- 使用现有有效可见指尖，过期、推测或非指尖不参与；模拟输入在该阶段保持可用。
- 互动不增加能量、不生成泡泡、不重复记录解救；重开、退出、错误会清理互动。
- 暂停冻结动作和时间，恢复不误开结算计时器；旋转保留互动次数和荷叶状态，重排布局并即时重绘，丢弃旧坐标。
- 互动结束后接续原有告别动画，随后有摄像头时合影，无摄像头时保持纯结果页。降低动态偏好继续生效。

## 家长验收（建议先试猫和狗）

1. 通关后先不要点其他按钮，等动物走近，食指轻碰它的光圈。看是否容易够到、回应是否及时。
2. 猫可以轻轻来回摸；狗和兔碰完收回，再碰第二下。确认动物会回应，能量不再增长。
3. 青蛙碰荷叶后应跳到那里，下一片发光位置应改变。双龙只需移动食指，不需要精确按住或点击。
4. 互动中暂停再继续、旋转手机，确认动物和指尖可见，进度保留。
5. 让孩子停一下，观察是否自然告别；也可点击「和朋友说再见」。之后应正常进入合影或纯成果页，继续游戏仍可用。

真实摄像头的手感、儿童能否直观理解光圈提示，仍以用户家庭环境体验为准。本轮没有更换识别模型。
