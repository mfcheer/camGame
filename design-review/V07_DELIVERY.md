# v0.7｜萌萌兔与林间小径

2026-11-13。本轮用户授权：在保留现有玩法的基础上，提升底部动物、布景、跑道与互动动画。

## 实现

- 新增本地二进制模型 `public/models/forest-bunny.glb`（约1.2MB），使用融合曲面的头脸、口鼻与躯干、弯曲扁耳和立体脚掌。模型含命名关节支点，游戏可独立驱动头、耳、爪、脚、尾和领结。可编辑源 `src/rabbitModel.js`，用 `npm run build:assets` 重新导出。该资产为本项目代码生成的原创曲面模型，并非 Blender 人工雕刻或毛发模拟。
- `src/rescueAnimal.js` 负责命名支点动画；浏览器使用GLB，同源原生模型提供加载失败回退。兔跳按接触蓄力、蹬地、腾空和落地分段；腾空阶段推进位置，减少落脚滑动；终点回头挥爪后淡出。
- `src/sceneManager.js` 重做浅纵深林间小径、鹅卵石、苔藓、花草、蘑菇与灯笼花门。角色、路面和布景使用统一光照与落脚面，具备投影与接触阴影；静态路面按材质合批。
- 计分立即记录，进度点亮、松绳、角色回应与音效等待能量抵达领结。第五次到达后才解救；结算同时等待庆祝计时和动物告别完成，慢渲染不会遮住挥爪。
- 场景、动物与粒子按游戏有效时间推进；暂停冻结。重开恢复模型透明度、绳索、初始位置与进度，取消旧能量回调。
- 模拟标识移至左上；修复竖屏提示层ID不一致；调整窗口尺寸后重新计算现有泡泡的像素半径与安全位置，保留计分和双人轮次。泡泡避让顶部HUD及两角布景。

## 新版构图依据

旧版要求所有底部元素（含兔耳、跳跃和花门）总高≤8%H，与角色可辨识性冲突。本轮按已确认的方向放宽两角展示区：兔子约占屏高24%，中央路面落脚线仍在底部8%内。画面中央与上部保持透明，给真实人像、双手和泡泡留空。较矮横屏维持角色相对比例，不再二次缩小。

## 交付与边界

使用 `npm run dev:local` 启动本机HTTP预览，默认 `http://127.0.0.1:5175/`；点击鼠标/触控板模拟体验。原HTTPS入口保留用于局域网设备。

当前是可玩的童话3D样板；没有实现真实毛发模拟、连续蒙皮骨骼或电影级材质。动画采用可编辑的关节支点和时序曲线。真实摄像头环境中的叠加效果、儿童实际使用、移动硬件性能和发热仍需实测，浏览器模拟与视口检查不代表真机通过。
